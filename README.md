## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/simple-interest.sh.git
cd simple-interest.sh
chmod +x *.sh
./script.sh
```
> Replace `script.sh` with the actual script name.
